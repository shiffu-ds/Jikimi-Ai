# پولیس / عدالت: ثبوت کی تصدیق کیسے کریں

1. PDF پر QR کوڈ اسکین کریں یا `/verify/EV-...` لنک کھولیں (لاگ ان کی ضرورت نہیں)۔
2. صفحہ ہر جانچ دکھاتا ہے: منشور کا ہیش، سرور دستخط، کیمرہ ڈیوائس دستخط، ویڈیو فائل، PDF، مرکل ثبوت، ٹائم اسٹیمپ۔
3. **اپنی فائل خود جانچیں:** PDF یا کلپ صفحے پر ڈالیں — ہیش آپ کے براؤزر میں بنتا ہے، فائل کہیں نہیں جاتی۔
   ایک بائٹ کی تبدیلی پر بھی نتیجہ "میل نہیں کھاتی" آئے گا۔
4. آزاد جانچ: سرور اور ڈیوائس کی public keys `/v1/keys/server` اور `/v1/keys/devices/<key_id>` پر موجود ہیں
   (Ed25519، SHA-256، RFC 6962، OpenTimestamps)۔
