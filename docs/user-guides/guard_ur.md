# گارڈ گائیڈ — جکیمی گارڈ ایپ

**ایپ کھولیں:** فون کے براؤزر میں سائٹ کا پتہ `/guard/` کھولیں اور "ہوم اسکرین پر شامل کریں" دبائیں۔
پہلی بار **"آواز آن کریں"** ضرور دبائیں تاکہ الارم کی آواز آئے۔

| جب یہ ہو | آپ یہ کریں |
|---|---|
| لال کارڈ اور الارم | ویڈیو تصویر اور اردو وجہ پڑھیں/سنیں، موقع پر جا کر دیکھیں |
| آپ نے دیکھ لیا | **"دیکھ لیا"** دبائیں (ورنہ 60 سیکنڈ بعد سپروائزر کو اطلاع جائے گی) |
| کچھ غلط نہیں تھا | **"غلط الارم"** دبائیں — اس سے سسٹم بہتر ہوتا ہے |
| مدد چاہیے | **"مدد چاہیے"** یا نیچے **SOS** کو 2 سیکنڈ دبا کر رکھیں |

**انٹرنیٹ نہ ہو تو:** الرٹ SMS پر آئے گا، مثلاً
`JIKIMI: Gate-2 par mashkook bike (2 sawar) 4 chakkar, 23:41. Code A7F2. Jawab: 1=dekh liya 2=ghalat`
جواب میں صرف `1` بھیجیں (یا `1 A7F2`)۔ `2` = غلط الارم، `3` = مدد۔

**یاد رکھیں:** سسٹم صرف اشارہ دیتا ہے؛ فیصلہ آپ کا ہے۔ کسی کو "چور" نہ کہیں — "مشکوک حرکت" دیکھیں اور جانچ کریں۔

## ذاتی حفاظت کے الرٹ (نئے)

یہ الرٹ کسی کی **حرکت** دیکھ کر آتے ہیں — سسٹم کسی کا چہرہ، جنس یا عمر نہیں پہچانتا، اس لیے یہ ہر
ایک کی حفاظت کرتے ہیں۔ یہ کسی جرم کی پیشگوئی نہیں، صرف یہ اشارہ ہے کہ وہاں جا کر دیکھنا چاہیے۔

| الرٹ | مطلب | آپ یہ کریں |
|---|---|---|
| **چھینا جھپٹی کا شبہ (پیدل)** | کوئی پیدل کسی راہگیر کے بالکل قریب آیا اور پھر بھاگ گیا (اکثر فون) | فوراً موقع پر جائیں، متاثرہ شخص سے پوچھیں |
| **کسی کو خطرہ · پیچھا** | کوئی کافی دیر سے کسی کے چند قدم پیچھے ہے، وہ رکے تو یہ بھی رکے | قریب جا کر خیریت پوچھیں؛ راستے میں ساتھ رہیں |
| **کسی کو خطرہ · گھیراؤ** | کئی لوگوں نے ایک شخص کو چاروں طرف سے گھیر لیا | فوراً جائیں، ساتھی گارڈ کو بلائیں |
| **کسی کو خطرہ · ہاتھا پائی / زبردستی کھینچنا** | دو لوگوں میں زور زبردستی، یا کوئی کسی کو کھینچ کر لے جا رہا ہے | فوراً جائیں، سپروائزر کو بتائیں |
| **کسی کو خطرہ · زبردستی گاڑی میں** | ہاتھا پائی کے بعد کسی کو گاڑی میں بٹھا کر گاڑی فوراً چلی گئی | فوراً سپروائزر کو بتائیں اور **15** پر کال کریں؛ گاڑی کا رنگ اور سمت نوٹ کریں |
| **کسی کو خطرہ · گر گیا** | کوئی اچانک گرا اور اٹھا نہیں | فوراً مدد کے لیے جائیں (ضرورت ہو تو 1122) |
| **بائیک چوری کا شبہ** | کھڑی بائیک پر کوئی دیر تک جھکا رہا پھر لے گیا | دیکھیں کیا یہ مالک ہی تھا؛ نہ ہو تو سپروائزر کو بتائیں |
| **بھگدڑ** | کئی لوگ اچانک ایک جگہ سے ہر طرف بھاگے | خود کو محفوظ رکھیں، سپروائزر کو فوراً بتائیں |

رات کو اور جب آس پاس کوئی نہ ہو تو "پیچھا" اور "گھیراؤ" بھی **زیادہ** درجے کے الرٹ ہوتے ہیں اور SMS پر بھی آتے ہیں۔
کسی پر الزام نہ لگائیں: ساتھ چلتے دوست، خاندان، بچوں کا کھیل یا گاڑی کا مالک بھی ایسا لگ سکتا ہے۔
