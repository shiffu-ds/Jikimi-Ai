# ADR-0013: Guard app as a PWA inside the dashboard

- **Status:** accepted (revised in v2.4)
- **Date:** 2026-10-23
- **Feature / gap:** F12, F22

## Context
Cheap Android phones; one codebase.

## Decision
`/guard/` in the same Next.js app with its own manifest + service worker; offline queue for acks and SOS.

## Consequences
No app store; Web Push for closed apps is a roadmap item (alerts arrive while the app is open; SMS covers the rest).
